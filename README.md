## 🧠 What is BotSignal Latam?

BotSignal Latam is an algorithmic trading signal service built for the Latin American market. Signals are generated by quantitative algorithms — not manual analysis — and delivered instantly to subscribers via Telegram with zero delay.

**Signal sources:**
- Pine Script v5 strategies on TradingView (NQ Edge Pro and others)
- Options scanner powered by Black-Scholes + Greeks (OptionsGuru engine)
- CCL arbitrage detector (CCL Radar v2 engine)
- Crypto momentum signals (Binance / KuCoin)

## 🏗️ Signal Pipeline Architecture

```
TradingView Pine Script Strategy (NQ Edge Pro)
        │
        ▼
  Webhook Alert → Render Server
        │
        ▼
  Signal Processor (Python)
  ┌─────────────────────────────┐
  │  Validate signal            │
  │  Format message             │
  │  Apply risk filters         │
  └─────────────────────────────┘
        │
        ▼
  Telegram Bot API
        │
        ▼
  @BotSignalLatam Channel → Subscribers
```
